# AI Landing to Ads

Скилл для [Claude Code](https://docs.anthropic.com/en/docs/claude-code), который читает контент посадочной страницы (или другого источника) и создаёт на его основе готовые тексты рекламных объявлений для **Яндекс Директа** и **VK Рекламы** — в структурированном JSON-файле, пригодном для переноса в рекламные кабинеты.

## Задача

Написание рекламных объявлений по лендингу — рутинная и повторяющаяся работа: нужно выжать из страницы УТП, разложить информацию по ограничениям площадок (символы в заголовках и описаниях), ничего не выдумать и не задублировать. Скилл автоматизирует это: агент читает источник и формирует комплект текстов сразу в нужной структуре и с учётом лимитов символов.

## На входе

Один источник на прогон:

- статья;
- новость;
- короткий пост;
- фрагмент рассылки;
- ссылка плюс цитата или краткое описание.

Если источников несколько, агент попросит выбрать один или обработает их по очереди.

## На выходе

Один JSON-файл `texts/YYYY-MM-DD-landing-to-ads.json` с двумя блоками:

### Яндекс Директ (`yandex_direct`)

| Поле | Что содержит | Лимит |
|---|---|---|
| `headlines` | 7 вариантов заголовка — самая главная информация о предложении | до 54 символов |
| `descriptions` | 3 варианта описания — дополнительная, менее важная информация | до 89 символов |
| `url` | ссылка на посадочную страницу | — |

Заголовки и описания комбинируются при показах, поэтому между ними нет дублирования фактов — каждый вариант несёт свою часть информации.

### VK Реклама (`vk_ads`)

| Поле | Что содержит | Лимит |
|---|---|---|
| `descriptions` | 3 варианта общего описания предложения | до 300 символов |
| `title` | заголовок — название организации со страницы | до 25 символов |
| `short_description` | короткое описание | до 90 символов |
| `button_text` | текст рядом с кнопкой действия, побуждающий к действию | до 25 символов |
| `url` | ссылка на посадочную страницу | — |

Дополнительно в корне файла сохраняется `source_url` — источник, по которому созданы тексты.

## Польза

- **Экономия времени**: комплект объявлений для двух площадок за один прогон вместо ручного набора текстов.
- **Единый формат**: результат всегда в одинаковой JSON-структуре — удобно хранить, сравнивать версии и переносить в кабинеты.
- **Гигиена фактов**: агенту запрещено додумывать факты — цифры, даты, цитаты, названия и ссылки берутся только из источника; спорные места помечаются `[уточнить]`.
- **Соблюдение лимитов**: символьные ограничения Директа и VK учтены в схеме, тексты пишутся сразу под них.

## Установка

1. Скопируйте файл `ai-landing-to-ads.md` в каталог скиллов Claude Code:
   - проектный: `.claude/skills/ai-landing-to-ads/SKILL.md`;
   - личный: `~/.claude/skills/ai-landing-to-ads/SKILL.md`.
2. При необходимости поправьте путь вывода в разделе «Порядок работы» (по умолчанию `~/pa-finance/texts`).
3. Запросите у агента: «создай объявления по ссылке https://…» — скилл подхватится автоматически.

```
├── README.md

```

## Пример использования

> **Пользователь:** Сделай тексты для Директа и VK по https://example-shop.ru/aktsiya
>
> **Агент:** читает страницу, проверяет, что фактов достаточно, создаёт `2026-10-28-landing-to-ads.json` с полным комплектом объявлений.

Пример результата смотрите в [texts/2026-10-08-landing-to-ads.json](texts/2026-10-08-landing-to-ads.json) — данные в нём обобщены для публикации.

## Ограничения

- Скилл готовит **только тексты** — запуск рекламы, кабинеты и биллинг остаются за человеком.
- Качество объявлений упирается в качество источника: если на лендинге мало фактов, часть текстов придётся уточнять вручную.
